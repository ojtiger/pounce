Pounce

맥 알림창 위치 변경

macOS 는 알림 배너를 화면 오른쪽 위에만 띄웁니다. Pounce 는 그 배너를 가로채 화면 가운데 — 또는 원하는 아홉 자리 중 하나에 카드로 보여줍니다.

brew install --cask ojtiger/tap/pounce

macOS 14 이상 · 무료 · 오픈소스 · 첫 실행 때 손쉬운 사용 권한이 필요합니다.

무엇을 바꾸고, 무엇을 그대로 두나

바꾸는 것은 위치와 생김새뿐입니다. 집중 모드, 방해금지, 알림 소리, 알림 센터 기록, 눌렀을 때 열리는 화면까지 macOS 규칙 그대로입니다. 알림을 대신 받아 다시 만들어 내는 방식이 아니라, 시스템이 그리려던 배너를 화면에 닿기 전에 치우고 그 내용을 카드로 옮겨 그립니다.

  • 위치는 화면 아홉 자리 중 선택, 끌어서 미세 조정
  • 모니터가 여러 대면 알림이 뜬 그 화면에 표시
  • 같은 앱 알림은 카드 하나로 묶임
  • 카드 크기·표시 시간·테마·강조색·소리 설정
  • 메뉴 막대 아이콘 숨기기
  • 한국어 · English · 日本語 · 简体中文 등 17개 언어

설치

brew install --cask ojtiger/tap/pounce

홈브루를 쓰지 않는다면 릴리스에서 zip 을 받아 /응용 프로그램 에 넣으면 됩니다. 첫 실행 때 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 Pounce 를 켜 주세요. 알림 배너를 읽고 옮기는 데 필요한 권한입니다.

자주 묻는 것

맥 알림창 위치를 시스템 설정에서 바꿀 수 있나요?

없습니다. macOS 는 알림 배너 위치를 오른쪽 위로 고정해 두었고, 설정에 그걸 옮기는 항목이 없습니다. Pounce 같은 앱이 필요한 이유입니다.

알림을 화면 가운데로 옮기면 하던 일을 가리지 않나요?

카드는 표시 시간이 지나면 사라지고, 마우스를 올리면 기다립니다. 가운데가 부담스러우면 아래 가운데나 왼쪽 위처럼 덜 걸리는 자리로 옮겨 두면 됩니다.

알림을 놓치지 않으려고 쓰는 건가요?

대부분 그렇습니다. 큰 화면일수록 오른쪽 위는 시선 밖입니다. 작업 중인 창 근처로 알림을 옮기면 놓치는 일이 줄어듭니다.

알림 내용이 어디로 전송되나요?

아닙니다. 알림은 이 맥 안에서만 읽히고 그려집니다. 밖으로 나가는 통신은 새 버전이 나왔는지 확인하는 것 하나뿐이고, 그것도 설정에서 끌 수 있습니다.

어떤 맥에서 되나요?

macOS 14 소노마 이상, 애플 실리콘과 인텔 모두 됩니다. macOS 26 에서는 시스템 유리 효과를, 그 이전에서는 서리 유리를 씁니다.
